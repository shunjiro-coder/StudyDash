# 指示
- 教材の重要な内容だけを、構造的に整理する（見出しと箇条書きを使う）。
- {scope_line}
- 教材にない事実を創作しない。要約であり、感想や評価は書かない。
- 教材の主要な項目を落とさない（出力言語を変えても、拾う内容は同じになるようにする）。
- **重要: {lang_line}**
- 簡潔に。冗長な前置きや締めの文は不要。

# 出力形式
出力は **JSON オブジェクト1個のみ**（前置き・説明・コードフェンス ``` は一切付けない）。次の形にする：
{{"summary_md": "Markdown形式のまとめ。見出しは ## 、箇条書きは - を使う。"}}

ルール：
- 有効な JSON のみを出力する。
- summary_md は Markdown 文字列1個にまとめる。
