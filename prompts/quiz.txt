# 出力形式
出力は **JSON オブジェクト1個のみ**（前置き・説明・コードフェンス ``` は一切付けない）。次の形にする：
{{"questions": [
  {{"type": "written", "question": "問い", "answer": "模範解答"}},
  {{"type": "choice", "question": "問い", "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"], "answer": "正解（choices のいずれかと完全一致）"}}
]}}

ルール：
- 有効な JSON のみを出力する。
- written 型は question（問い）と answer（模範解答）を持つ。choices は付けない。
- choice 型は choices（ちょうど4個）と answer（choices のどれか1つと完全一致する正解の文字列）を持つ。正解と言えるのはちょうど1個だけにし、誤答の3個は正解と長さ・文法・カテゴリを揃え（形で正解が分からないように）、それぞれこの教材の学習者が実際にしがちな誤りを反映させる。「すべて正しい／どれも正しくない」・冗談の選択肢・正解だけ目立って長い選択肢・意味が重なる選択肢は禁止。
- answer は簡潔で明確に。ただし自己採点できるだけの中身を必ず入れる：
  問いの語をそのまま言い換えただけの循環的な解答にしない、問いが求めた要素を
  すべて答える、問いが「順に」と指定していれば解答もその順で書く。written の
  模範解答で触れるべき点が複数あるときは、「XがYを引き起こすと述べる」のように
  ○×で確認できる形で各点を書く（「概念をよく説明している」のような言い換えは不可）。
- questions 配列はちょうど {count} 個にする。
- 出力前に各問題を確認：教材だけで答えられるか／問題文が答えを漏らしていないか／choice は正解がちょうど1個で answer が choices と完全一致か／有効な JSON か。満たさない問題は修正または差し替え、JSON オブジェクト1個のみを出力する。
