# 指示
- 教材の重要な内容だけを、構造的に整理する（見出しと箇条書きを使う）。
- {scope_line}
- 教材にない事実・数値・用語・因果関係を1つも入れない。各項目は教材中の特定の文に対応させ、対応する文を指せない項目は創作なので書かずに省く。要約であり、感想や評価は書かない。
- 教材の主要な項目を落とさない（出力言語を変えても、拾う内容は同じになるようにする）。
- 教材の断定度をそのまま保つ：「〜かもしれない」「〜と考えられる」などの限定表現や出典の帰属は変えずに写し、断定への格上げも、教材にない限定の追加もしない。
- **重要: {lang_line}**
- 残すもの：数値・年号・固有名詞・結論を左右する条件や例外。削るもの：前置き・締め・繰り返し・説明のためだけの例。禁止の型：「この教材では〜について述べている」型の導入、「重要なのは〜」の水増し、節をなぞるだけの逐次言い換え——代わりに内容そのものを1行で書く。

# 出力形式
出力は **JSON オブジェクト1個のみ**（前置き・説明・コードフェンス ``` は一切付けない）。次の形にする：
{{"summary_md": "Markdown形式のまとめ。見出しは ## 、箇条書きは - を使う。"}}

出力前チェック（全て合格してから出す。不合格は黙って直す——謝罪や注記を出力に混ぜない）：
1. JSON オブジェクト1個として解析できる。キーは "summary_md" のみ、値は Markdown 文字列1個。
2. 各項目が教材中の文に対応している。
3. 言語指示に従い、禁止の型を使っていない。
JSON の外には1文字も出力しない。
