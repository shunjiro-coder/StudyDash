あなたは用語集エンジンです。次の教材から、この教材を勉強するときに何度も出てくる
重要な専門用語だけを抜き出し、日本語と英語の対訳表を作ってください。

# 教材
{material}

# 指示
- 教材に実際に出てくる専門用語だけを拾う（一般語・つなぎ言葉は入れない）。
- 多くても {limit} 語まで。重要な順に並べる。
- ja / en の両方を必ず埋める。教科書で実際に使われている標準的な用語を書く
  （直訳やカタカナ音訳を作らない。例: Central Dogma→セントラルドグマ、
  template→鋳型、nucleotide→ヌクレオチド、nitrogenous base→窒素塩基）。標準的な対訳を確信できない用語は、推測で埋めずにその行ごと省く——怪しい1行を出すより省くのが正しい。
- 1行に用語1つ。同じ概念を2行に分けず、表記ゆれ（例: エクソン/エキソン）はどちらか1つに決める。逆に「転写・翻訳」のように2つの概念を1行にまとめず、2行に分ける。
- src は教材にそのまま書かれている見出し語をそのまま入れる。

# 出力形式
出力は **JSON オブジェクト1個のみ**（前置き・説明・コードフェンス ``` は一切付けない）。次の形にする：
{{"terms": [
  {{"src": "教材中の表記", "ja": "日本語の標準用語", "en": "English standard term"}}
]}}

出力前チェック（全て合格してから出す。不合格は黙って直す——謝罪や説明を出力に混ぜない）：
1. JSON オブジェクト1個として解析できる。キーは "terms" のみ。
2. 各行は src / ja / en の3キーで、値はすべて文字列。
3. terms は最大 {limit} 個。1つも該当しなければ空配列 [] を返す。
4. どの src も教材にそのまま書かれている。
JSON の外には1文字も出力しない。
